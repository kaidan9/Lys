LYS — Schémas constitutionnels

Les fichiers constitution-I.svg à constitution-V.svg sont des redessins vectoriels réalisés à partir des cinq documents fournis par l'utilisateur.
Les documents originaux sont conservés dans le sous-dossier sources/.

Correspondances :
- constitution-I.svg   <- sources/I.png   : Directoire / Constitution de l'an III (1795)
- constitution-II.svg  <- sources/II.gif  : schéma intitulé « Président puis Empereur » ; son intitulé original est conservé et sa portée est signalée dans la fiche.
- constitution-III.svg <- sources/III.png : organisation institutionnelle de la IIIe République
- constitution-IV.svg  <- sources/IV.webp : schéma de la IVe République
- constitution-V.svg   <- sources/V.png   : schéma de la Ve République ; les durées de mandat figurant dans la source sont conservées comme telles.

Le bouton RV reste disponible dans le sélecteur de périodes du site. Aucun schéma RV n'ayant été fourni, le bouton C affiche un message explicatif au lieu d'inventer un diagramme.
